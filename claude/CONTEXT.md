开发一个面向AI文献阅读的 Python CLI 批量预处理工具：批量将 PDF、DOCX 学术论文转为优化版 Markdown。
一次性完整输出，不要中途提问。输出顺序严格按照：
1. 需求分析
2. 系统设计：模块拆分、依赖选型、数据结构
3. 项目目录结构
4. 全部源代码（每个文件分开，带类型注解、异常捕获、注释）
5. 单元测试代码
6. 安装、运行示例
7. 已知局限、后续迭代方向

业务背景：
大量学术文献（论文、报告），批量预处理，输出干净的 Markdown，专门用于后续投喂给大模型阅读、做文献综述、信息抽取、知识整理。重点不是还原排版，而是提升文本质量，减少AI被噪声干扰。

功能需求：
1. 文件扫描模块
递归扫描 --source 目录，收集 .pdf / .docx；支持过滤规则，可跳过已经处理过的文件；记录文件原始相对路径，在 --dest 输出目录镜像目录结构。

2. DOCX 文献解析模块（学术文档）
- 提取段落、标题层级，尽量映射为 Markdown # ## ###
- 表格转为 Markdown 表格；合并单元格降级处理
- 图片位置插入占位：<!-- FIGURE: 原文档图片 -->
- 自动识别并剔除重复页眉、页脚、页码

3. PDF 文献解析模块（重点）
使用 pdfplumber。
- 文本型PDF：提取文字，尝试识别标题层级；尽量按段落断句，不要整行粘连。
- 自动尝试剔除页眉、页脚、页码。
- 识别页面内表格，转为 markdown 表格。
- 图片位置插入占位：<!-- FIGURE: PDF页面图片 -->
- 扫描版PDF（无文本层）直接标记【SCANNED DOCUMENT: 无法提取文本】，不继续处理。
- 公式：保留原始文本，标记 <!-- FORMULA -->

4. AI友好文本清洗模块【新增，最关键】
转换得到原始文本后，执行清洗：
- 去除多余换行、大量空白字符
- 识别文献常见区块：摘要、引言、方法、结果、讨论、参考文献，在md中增加标记注释 <!-- SECTION: Abstract --> 方便后续AI识别章节
- 尝试识别参考文献块，可选参数 --strip-reference 把参考文献整体移除（很多时候做文献精读不需要参考文献，减少token消耗）
- 去除单词断字（例如 hyphenated words at line-break: meth-od → method）
- 保留原文内容，不做语义改写，只做格式与噪声清理

5. 输出写入模块
输出 .md 文件，保持原目录结构。
可选参数：
--overwrite 覆盖已存在md，默认false
--strip-reference 自动删除参考文献部分
--skip-scanned 跳过扫描PDF，不生成空md
--no-table 可选，不转换表格，表格替换成占位注释

6. 日志与报告
运行时输出进度；任务结束生成 conversion_report.md，包含：
成功文件列表；失败文件+错误原因；扫描PDF清单；统计总文件数、成功、失败、跳过数量。

约束：
- 不要引入重量级OCR库，本版本不做图片PDF文字识别；扫描PDF仅标记。
- 捕获所有异常：文件损坏、权限错误、解析报错，单个文件失败不中断整个批量任务。
- 代码风格：类型注解，清晰注释，工程化模块化。
