# CONTEXT.md — 项目上下文（已修订）

开发一个面向AI文献阅读的 Python CLI 批量预处理工具：批量将 PDF、DOCX 学术论文转为优化版 Markdown。
一次性完整输出，不要中途提问。输出顺序严格按照：
1. 需求分析
2. 系统设计：模块拆分、依赖选型、数据结构
3. 项目目录结构
4. 全部源代码（每个文件分开，带类型注解、异常捕获、注释）
5. 单元测试代码
6. 安装、运行示例
7. 已知局限、后续迭代方向

## 业务背景
大量学术文献（论文、报告），批量预处理，输出干净的 Markdown，专门用于后续投喂给大模型阅读、做文献综述、信息抽取、知识整理。重点不是还原排版，而是**提升文本质量，减少 AI 被噪声干扰**。

## 功能需求

### 1. 文件扫描模块
递归扫描 `--source` 目录，收集 `.pdf` / `.docx`；支持过滤规则，可跳过已经处理过的文件；记录文件原始相对路径，在 `--dest` 输出目录镜像目录结构。
- 公共 CLI 参数：`--source`（必填）、`--dest`（必填）、`--overwrite/--strip-reference/--skip-scanned/--no-table/--no-columns`。

### 2. DOCX 文献解析模块（学术文档）
- 提取段落、标题层级，尽量映射为 Markdown `# ## ###`
- 表格转为 Markdown 表格；合并单元格降级处理（以换行/空格拼贴）
- 图片位置插入占位：`<!-- FIGURE: 原文档图片 -->`
- 自动识别并剔除重复页眉、页脚、页码（python-docx 仅遍历正文本体，天然排除页眉页脚，无需额外处理即可达标）

### 3. PDF 文献解析模块（重点，使用 pdfplumber）
- 文本型 PDF：提取文字，尝试识别标题层级
- **段落重排**：尽量按段落断句，不要整行粘连。此为启发式，段落边界未必 100% 准确，目标为"较裸文本明显提升"
- **多栏检测**：按文字 x0 坐标聚类识别单栏/多栏；多栏时按栏切分后按栏序输出，避免左右栏交错。可由 `--no-columns` 关闭
- 页眉页脚/页码剔除：仅剔除**跨页重复出现**的行（页眉/页脚/页码）；**第 1 页不处理**，保护题目/期刊/DOI/作者等元数据
- 识别页面内表格，转为 markdown 表格；无完整框线的复杂表降级为文本拼贴
- 图片位置插入占位：`<!-- FIGURE: PDF页面图片 -->`
- **扫描版 PDF 判断**：先尝试提取文本，再兜底检查是否存在任何文字对象；仍无文本层才标记 `【SCANNED DOCUMENT: 无法提取文本】`。加密/仅图块/损坏文件也归入失败或跳过路径，不误判为正常文本
- 公式：保留原始文本，标记 `<!-- FORMULA -->`（符号可能错位，仅为占位与原文留存，不保证公式可读）

### 4. AI友好文本清洗模块【新增，最关键】
转换得到原始文本后，执行清洗：
- 去除多余换行、大量空白字符
- 识别文献常见区块：摘要、引言、方法、结果、讨论、参考文献，在 md 中增加标记注释 `<!-- SECTION: Abstract -->` 方便后续 AI 识别章节
- 尝试识别参考文献块，可选参数 `--strip-reference` 把参考文献整体移除（很多做精读不需要参考文献，省 token）。切前校验"References"标题后内容符合参考文献模式（编号/年份/作者），避免误切正文
- 去除单词断字：**仅当行尾为连字符且下一行以小写字母开头时**合并（`meth-\nod → method`）；真正的连字符词（`self-referential`、`co-author`）保留
- 保留原文内容，不做语义改写，只做格式与噪声清理

### 5. 输出写入模块
输出 `.md` 文件，保持原目录结构。
可选参数：
- `--overwrite` 覆盖已存在 md，默认 false
- `--strip-reference` 自动删除参考文献部分
- `--skip-scanned` 跳过扫描 PDF，不生成空 md
- `--no-table` 可选，不转换表格，表格替换成占位注释
- `--no-columns` 可选，关闭多栏切分（默认开启）

### 6. 日志与报告
运行时输出进度；任务结束生成 `conversion_report.md`，包含：
- 成功文件列表；失败文件 + 错误原因；扫描 PDF 清单；统计总文件数、成功、失败、跳过数量

## 约束
- 不引入重量级 OCR 库，本版本不做图片 PDF 文字识别；扫描 PDF 仅标记
- 捕获所有异常：文件损坏、权限错误、解析报错，单个文件失败不中断整个批量任务
- 代码风格：类型注解，清晰注释，工程化模块化
- 依赖选型：python-docx、pdfplumber、typer、logging

## 验收标准
优化版 Markdown 的客观兜底衡量（拒绝"凭感觉"）：
1. 对 `--source samplepapers` 全量跑通无未捕获异常，得到 conversion_report.md 且计数自洽（总 = 成功 + 失败 + 跳过）
2. 修复硬错误计数器下降：残留页码行数、跨页重复页眉行数、过度粘连的超长行数，均趋近 0
3. 单元测试覆盖：段落重排、断字合并、页眉剔除、章节/参考文献识别、扫描版/损坏文件边界
